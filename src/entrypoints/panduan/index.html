Panduan Manipulation Detector

Ekstensi ini membantu pembaca memeriksa cara sebuah pernyataan berusaha meyakinkan mereka.

Cara menggunakan

Buka linimasa For You atau Following, atau tab Top (Populer) atau Latest (Terbaru) di hasil pencarian X. Anda juga bisa membuka tautan detail untuk memeriksa unggahan utama. Jika sebuah unggahan memunculkan petunjuk pola retorika, pilih label merah seperti Indikasi Ad Hominem di atas teks unggahan untuk melihat kutipan dan penjelasannya. Gunakan popup untuk menjeda deteksi, memilih pola, atau menyembunyikan anotasi.

Aktifkan “Model lokal (eksperimental)” di popup untuk mencoba saran tambahan pada Ad Hominem, Dilema palsu, dan Tekanan rasa bersalah. Saran model ditandai sebagai indikasi awal dan menyertakan kutipan yang bisa Anda periksa. Eksperimen awal lebih banyak mengenali contoh sintetis daripada komentar manusia.

Untuk analisis online dengan Groq, masukkan API key akun Anda di popup lalu pilih “Simpan dan aktifkan”. Ekstensi memeriksa hingga sepuluh unggahan yang terlihat per permintaan. Di atas unggahan, status memuat, tanda centang, atau nama pola menunjukkan hasilnya. Jika kuota Groq tercapai, hasil sementara diberi label “Analisis lokal”.

Pola deteksi

  • Ad Hominem memakai serangan pribadi untuk menolak pendapat.
  • Dilema palsu mempersempit pilihan seolah hanya ada dua posisi.
  • Tekanan rasa bersalah memakai rasa wajib atau malu untuk mendorong tindakan.
  • Banding pada otoritas memakai status ahli untuk mengesampingkan pemeriksaan bukti.
  • Pertanyaan bermuatan mengandaikan tuduhan sudah terbukti.
  • Urgensi palsu memakai tekanan waktu untuk memaksa keputusan atau menghalangi verifikasi.
  • Whataboutism mengalihkan kritik dengan membahas tindakan pihak lain.
  • Strawman mengubah klaim menjadi versi yang lebih mudah diserang.

Whataboutism dan Strawman memerlukan kritik atau klaim asli yang tersedia untuk dibandingkan. Sebuah petunjuk dalam kalimat belum cukup untuk menyimpulkan niat penulis.

Kebijakan privasi

Secara bawaan, analisis teks berlangsung di perangkat Anda. Ekstensi menyimpan pengaturan, penghitung sesi, dan jumlah umpan balik berdasarkan pola dan alasan pilihan Anda. Teks unggahan, akun, dan alamat halaman tidak masuk ke penyimpanan ekstensi.

Jika Groq diaktifkan, teks unggahan yang terlihat dan kutipan yang diperlukan dikirim langsung ke Groq. Tautan, alamat email, dan sebutan akun di dalam teks disamarkan. API key tersimpan di perangkat dan pemakaian mengikuti kuota akun Groq Anda. Pilih “Putuskan Groq” untuk menghapus API key dan menghentikan pengiriman. Pada build pilot, popup menyebut Cloudflare Workers AI sebagai penyedia, dengan batas pemakaian harian yang disimpan di perangkat.

Gunakan “Atur ulang pengaturan” untuk menghapus preferensi. Di bagian “Umpan balik lokal”, Anda bisa menghapus umpan balik atau mengunduh salinan JSON secara manual.
